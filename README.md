# 视频首页 MP4 生成器（homepage_webui）

生成「一张或多张视频图片 + 音频 → MP4（可选同步字幕）」的一站式 WebUI 工具。

## 多图播放规则

- 可一次选择多张图片，也可继续追加；按选择顺序播放。
- 第 1 张图片是首页，主题文字和副标题只叠加在首页上。
- 单图时整段视频保持该图片。
- 多图时按 `1 → 2 → … → N → 1` 播放，结尾自动回到首页形成首尾闭环。
- 多图时开头首页和结尾首页各自最多播放 3 秒，随后快速进入内容图片；其余内容图片平均分配剩余音频时长。
- 音频较短、全部播放段均分后本来就不足 3 秒时，继续平均分配，不会强行延长首页。

## 默认参数（webui.py / 前端一致）

| 参数 | 默认值 |
|------|--------|
| 端口 | 8090 |
| 分辨率 | 默认按第 1 张图片的实际长宽自动输出（横图→横屏、竖图→竖屏）；可手动覆盖为横屏 1080p/4K/720p |
| 背景模式 | fit-blur（整图完整呈现） |
| 主标题 | 红黄双色，前半黄 #FFD700 + 后半红 #E60012，字号自适应（≈屏宽 92%），中心 y=0.44H；**可留空：留空则不加任何文字，直接使用原图（图片自带文字）** |
| 副标题 | 52px 白字 + 黑描边 + 半透明黑底条，位置 y=0.70H，≤100 字，超 3 行自动缩小至 28px |
| 字幕 | 默认开启；30px 黄字（可换白/青/橙）+ 黑描边 6px；位于副标题底条下方 56px 自动避让；无副标题时距底边 110px |
| 对齐算法 | silencedetect(-38dB, d=0.15) 检出全部停顿 → 取最长 n-1 个作句边界 → 自适应帧率对齐，零累积误差 |
| 视频编码 | macOS 默认使用 VideoToolbox + AudioToolbox；不可用时自动回退 libx264 ultrafast + AAC；单图无字幕 1fps、多图无字幕 5–25fps、有字幕 10fps |

## 核心接口

| 接口 | 说明 |
|------|------|
| `POST /api/generate` | multipart 提交 audio/image/script + 参数，返回 job_id |
| `GET /api/job/<id>/status` | 状态 + 日志（轮询） |
| `GET /api/job/<id>/result` | result.json（同步表 / 时长 / subtitle_enabled） |
| `GET /api/job/<id>/video` | MP4 播放（Range 支持） |
| `GET /api/job/<id>/download` | MP4 下载 |

## 口播文稿解析规则（2026-08-19 14:30 修订）

- **不再默认取文案首个标题作为主题**（用户明确取消该行为）；主题文字完全由界面「主题文字」输入框决定。
- 主题输入框**可留空**：留空时背景图不加任何文字（图片本身已带字即可直接使用），字幕/副标题仍按各自输入独立生效。
- MP4 文件名取第 1 张图片的文件名并将扩展名改为 `.mp4`。例如 `新闻首页.jpg` → `新闻首页.mp4`。
- 若桌面输出目录中已有同名视频，则保留旧文件并生成 `新闻首页_2.mp4`、`新闻首页_3.mp4`……

## 关键设计约束（红线）

1. 字幕与副标题/主标题**绝不重叠**：副标题底条区域由 make_homepage_bg.py 输出 `[subtitle-region]`，compose_video.py 以此为基准 + 56px 避让。
2. 字幕字号必须小于副标题（30 < 52），层级 4:1:0.6。
3. 背景图整图铺满（fit-blur 完整呈现 / cover 裁切铺满），不展示局部。
4. 主标题红黄双色、超大加粗、除主题外无其他文字；**主题留空则不渲染任何文字**。
5. 音画同步：绝对时间戳帧对齐，禁用逐段 concat 方案。
